# 用户清理与智能测试中心

本次在澄川现有项目上扩展用户清理、异步能力检测、默认保护策略和分级权限。保留账号列表的旧测试、编辑、导入、统计和批量操作。验证以 `verification/features/` 和 `verification/protection/` 实际日志为准。

## 清理无余额用户

入口：后台 → 用户管理 → 清理无余额用户。先生成管理员绑定的预览，查看候选后勾选确认再执行。每批最多 500 人，预览 10 分钟失效。

基础条件为余额 ≤ 0，最近使用时间严格早于数据库当前时间减 24 小时。现有 `LastUsedAt` 来自使用日志汇总，额外核查 API Key 最近使用记录、注册时间、登录及活跃时间。所有时间判断都在后端执行。

从未使用的账号不自动清理，包括注册已超过 24 小时的账号；管理员可单独检查其用途。管理员、超级管理员、系统/保护账号及有冻结资产、有效订阅或待处理业务的账号会排除。用户编辑页可设置清理保护。

执行时只处理预览里的候选，锁定用户及 API Key 后再次核查余额和活动；保留用户和业务历史，软删除用户及密钥。登录身份先归档到内部表，再解除绑定，允许原邮箱重新注册新用户。审计记录、完整用户 ID、零/负余额统计和执行结果在同一事务保存。同一预览重复提交返回原结果，条件变化的账号跳过。

## 管理账号测试

账号管理分为账号列表、智能测试、测试记录、测试设置。账号列表的轻量“测试”入口可选择单个或全部已启用测试；原连接测试保留在原菜单。

智能测试页支持账号搜索、账号类型、账号池/分组、账号状态、测试类型、结果、保护开关和仅异常筛选；选择账号后批量提交。卡片显示最后结果、耗时、历史次数、保护状态及风险提示。测试详情提供输入、结果、安全图像预览、原始响应、配置快照与错误。

测试提交立即入持久队列，由后台执行；页面轮询状态，刷新或离开页面不会删除任务。记录按次保存，历史支持账号、类型、状态、时间和分页查询。队列使用数据库租约及并发认领，过期工作进程不能覆盖新结果。测试不会自动修改保护策略。

智能测试使用已保存且未过期的 OAuth 凭据，不自动刷新、注册认证或发现项目，也不借令牌缓存回写路由。凭据过期或缺少过期时间会显示账号异常，需管理员先在原账号管理中单独刷新。Vertex 服务账号签发短期令牌仍可使用。受保护的 OpenAI OAuth 检测复用固定设备身份，每次使用独立会话和请求完整性校验。详见 `BF-002-intelligent-test-auth-isolation.md`。

默认题目已由用户确认：

| 测试 | 默认内容 | 评分含义 |
| --- | --- | --- |
| 鹈鹕 | 绘制骑自行车鹈鹕的独立 SVG | 有效静态 SVG 的结构/安全校验；不评判画面语义或美感 |
| 糖果 | 24 颗糖，先取走四分之一，再取余下一半，放回 3 颗 | 最后一行 `ANSWER: 12`；按配置的标准答案校验 |

模型、题目、超时、评分规则和标准答案可配置。评分是一次规则检测结果，不能据此证明上游模型整体能力或“降智”。SVG 经后端静态元素校验、前端净化后作为图片显示；不会将模型输出执行为 HTML。

快速测试会读取所选账号的可用模型并提供下拉选择；模型目录暂时不可用时仍可使用测试设置中的默认模型。针对 ChatGPT/Codex 账号，空模型或历史默认 `gpt-5.4` 在测试执行路径自动归一为 `gpt-5.3-codex`，避免上游返回“不支持该模型”的 400；普通网关路由不受影响，实际使用模型和配置快照会写入测试记录。

## 控制普通用户可见性

测试设置的“管理员可用”和“用户可查看”各自生效：前者控制新任务，后者控制公开历史。默认普通用户不可见。

用户在可用渠道页面的“账号详情 · 能力检测”区看到自己有权访问账号的公开结果；无公开结果时不显示该区域。用户使用专门的只读 API，不能创建测试、获取隐藏结果或修改策略。列表、历史、单条结果和图片都核查当前用户分组及当前可见性；公开 DTO 不包含账号备注、凭据、测试输入、原始响应或内部错误。

账号编辑器继续提供最小兼容、会话兼容、初代兼容、模式一、模式二、Node.js 24 对照和低并发稳定，并按平台/账号类型过滤适用策略。关闭须管理员明确确认并还原快照，批量只提供开启。本地已统一 HTTP/WSS 与测试身份，切换改为单次持久提交并检查账号版本，普通与批量保存保留受管字段。预览显示有效传输和全局覆盖原因，智能测试保存执行时策略快照。相关复现及独立数据库验证已通过，真实上游效果尚未验收。当前结果见项目根目录 `LOCAL_REPAIR_RESULTS_2026-09-14.md`；本次没有部署服务器。
